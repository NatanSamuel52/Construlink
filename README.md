
 # Construlink
#

  <img src="./01_home.png" alt="Logo do Construlink" >




 **Conectando clientes aos profissionais certos para cada serviço.**

O **Construlink** é uma plataforma desenvolvida para conectar clientes a profissionais das áreas de construção, manutenção e reformas.

A aplicação permite que clientes encontrem profissionais por especialidade ou região, visualizem seus perfis, acompanhem avaliações e solicitem contato para serviços.

---

## 🎯 Objetivo

Facilitar a conexão entre pessoas que precisam contratar serviços e profissionais que desejam divulgar seu trabalho.

---

## ✨ Funcionalidades

### 👤 Cliente

* Cadastro e login;
* Busca de profissionais;
* Pesquisa por especialidade ou região;
* Visualização de perfis;
* Favoritos;
* Solicitação de contato;
* Avaliação de profissionais.

### 🛠️ Profissional

* Cadastro e gerenciamento de perfil;
* Definição de especialidades;
* Portfólio de trabalhos;
* Recebimento de solicitações;
* Visualização de avaliações e estatísticas.

### 🛡️ Administrador

* Gerenciamento da plataforma;
* Visualização de clientes e profissionais;
* Acompanhamento de novos cadastros;
* Análise de denúncias.

---

## 🛠️ Tecnologias utilizadas

* **HTML5**
* **CSS3**
* **JavaScript**

Atualmente, o projeto funciona como um **protótipo navegável**, com dados simulados e funcionalidades executadas diretamente no navegador.

---

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/construlink.git
```

Acesse a pasta:

```bash
cd construlink
```

Abra o arquivo `construlink.html` no navegador ou utilize a extensão **Live Server** do Visual Studio Code.
